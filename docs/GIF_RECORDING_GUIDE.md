# 仪表板GIF录制指南

本文档指导如何录制Streamlit仪表板的交互演示GIF。

## 准备工作

### 1. 安装录屏软件
推荐使用以下工具（选择其一）：

**Windows:**
- [ScreenToGif](https://www.screentogif.com/) (免费、轻量)
- [OBS Studio](https://obsproject.com/) (免费、专业)

**macOS:**
- [GIPHY Capture](https://giphy.com/apps/giphycapture) (免费、简单)
- [Kap](https://getkap.co/) (免费、开源)

**Linux:**
- [Peek](https://github.com/phw/peek) (简单GIF录制)
- [OBS Studio](https://obsproject.com/) (功能全面)
